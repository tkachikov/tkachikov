### ⏱ &nbsp;Chronos — my main project

<a href="https://github.com/tkachikov/chronos">
  <img src="https://github.com/tkachikov/chronos/raw/master/images/logo.png" alt="Chronos" width="160" align="right">
</a>

**[Chronos](https://github.com/tkachikov/chronos)** is a web UI for Laravel Scheduling: manage your artisan commands and their schedules without touching the code.

- 🗓 &nbsp;create, edit and switch schedules on/off from the browser
- ▶️ &nbsp;run commands from the queue or **in real time** — with a live terminal, interactive answers and SIGTERM/SIGKILL
- 📜 &nbsp;run history with logs, execution time and memory usage per run
- 🧩 &nbsp;Laravel 9 – 13, PHP 8.2+
